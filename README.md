# Sumie Exorcist — Android and Windows releases

Official Android and Windows downloads for Sumie Exorcist, an offline game about learning kanji, hiragana and katakana through writing and spirit battles. The game supports English and Polish.

## Download

Browse the [published releases](https://github.com/barcicki/sumie-exorcist-releases/releases).

APK assets include the version in their filenames, for example `sumie-exorcist-1.2.3.apk`. Use the published releases page to choose a version. The game website resolves the download URL from the most recently published release, so it follows the current versioned filename.

On Android, download and open the APK. Your device may ask you to allow installation from the browser or file manager you used.

On Windows, download `sumie-exorcist-X.Y.Z-windows.zip`, extract the whole archive, and run `SumieExorcist.exe`. The Windows download is also available in the Downloads section of the [game website](https://sumie-exorcist.pages.dev/).

## About this repository

This public repository distributes compiled APK and Windows ZIP files and release notes. The game source code is maintained separately in a private repository. Packages are attached as release assets rather than committed to Git.

Building and publishing are controlled by GitHub Actions in the private source repository. This repository does not need its own Actions workflow. Automation requires a credential with Contents: write permission for this repository; the source repository token does not automatically grant access here.
